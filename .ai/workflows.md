> Content repo (Markdown only). No build; verification is manual (render + links).

## Bugfix (broken badge / link / rendering / stale claim)

1. Reproduce the issue. 2. Apply the minimal fix; report any issue in the alternative; edit it only when included in the request.
3. Verify links/badges resolve and Markdown renders. Summarize changed lines.

## Refactor (restructure / rewrite)

1. List facts/links/badges that must be preserved. 2. Propose the new structure first.
3. Rewrite for clarity, preserving every fact. Provide a before/after summary.

## Feature (new section / widget)

1. Confirm it's truthful and adds value. 2. Prefer lightweight, reliable elements.
3. Keep coherent with the canonical README.

## Architecture / structure review

1. Map each README's section structure. 2. Evaluate ordering/hierarchy for a 10-second skim.
3. Recommend a canonical structure + editorial guidelines (capture in `References/`).

## Performance / rendering & SEO review

1. Inventory external images/badges; flag heavy/flaky ones. 2. Confirm GFM renders.
3. Assess keyword/heading clarity for discoverability; suggest lighter alternatives.
